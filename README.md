# Anthropic 课程

欢迎来到 Anthropic 教育课程。本仓库目前包含五门课程。我们建议按以下顺序完成这些课程：

1. [Anthropic API 基础](./anthropic_api_fundamentals/README.md) - 教你使用 Claude SDK 的基础知识：获取 API 密钥、使用模型参数、编写多模态提示词、流式响应等。
2. [提示词工程互动教程](./prompt_engineering_interactive_tutorial/README.md) - 关键提示词技术的综合分步指南。[[AWS Workshop 版本](https://catalog.us-east-1.prod.workshops.aws/workshops/0644c9e9-5b82-45f2-8835-3b5aa30b1848/en-US)]
3. [现实世界提示词](./real_world_prompting/README.md) - 学习如何将提示词技术融入复杂的现实世界提示词中。[[Google Vertex 版本](https://github.com/anthropics/courses/tree/vertex/real_world_prompting)]
4. [提示词评估](./prompt_evaluations/README.md) - 学习如何编写生产级别的提示词评估，以衡量提示词的质量。
5. [工具使用](./tool_use/README.md) - 教你使用 Claude 在工作流程中成功实现工具使用所需的一切知识。

**请注意，这些课程通常使用我们成本最低的模型 Claude 3 Haiku，以帮助跟随学习的学生控制 API 成本。如果你愿意，也可以使用其他 Claude 模型。**
