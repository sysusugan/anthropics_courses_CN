# Anthropic 提示工程互动教程

## 课程介绍与目标

本课程旨在帮助你全面、循序渐进地了解如何在 Claude 中设计出最优提示词。

**完成本课程后，你将能够**：
- 掌握良好提示词的基本结构
- 识别常见的失败模式并学习解决这些问题的"80/20"技巧
- 了解 Claude 的优势与劣势
- 从零开始为常见用例构建强有力的提示词

## 课程结构与内容

本课程的设计让你有大量机会亲自练习编写和调试提示词。课程分为 **9 个章节及配套练习**，以及一个包含更高级方法的附录。建议你 **按章节顺序学习本课程**。

**每个课程底部都有一个"示例演练区"**，你可以自由尝试课程中的示例，亲眼看看修改提示词如何改变 Claude 的回复。同时还有一份[参考答案](https://docs.google.com/spreadsheets/d/1jIxjzUWG-6xBVIa2ay6yDpLyeuOh_hR_ZB75a47KX_E/edit?usp=sharing)。

注意：本教程使用我们最小、最快、最便宜的模型 Claude 3 Haiku。Anthropic 还有[另外两个模型](https://docs.anthropic.com/claude/docs/models-overview)，Claude 3 Sonnet 和 Claude 3 Opus，它们比 Haiku 更智能，其中 Opus 是最智能的。

*本教程也有 [Google Sheets 版本（使用 Anthropic 的 Claude for Sheets 扩展）](https://docs.google.com/spreadsheets/d/19jzLgRruG9kjUQNKtCg1ZjdD6l6weA6qRXG5zLIAhC8/edit?usp=sharing)。我们推荐使用该版本，因为它更加方便易用。*

当你准备好开始时，请前往 `01_Basic Prompt Structure` 开始学习。
